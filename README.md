# Xiunan Interactive Entertainment Technology Co., Limited

Corporate website for Xiunan Interactive Entertainment Technology Co., Limited — a Hong Kong-based technology company specializing in interactive entertainment solutions.

## Features

- Fully English, international corporate presentation
- Modern dark theme with premium gradient accents
- Responsive design (desktop, tablet, mobile)
- Smooth scroll navigation and reveal animations
- Contact form with email integration
- SEO-friendly semantic HTML

## Structure

```
GW/
├── index.html          # Main page
├── css/
│   └── styles.css      # Styles
├── js/
│   └── main.js         # Interactions
├── assets/

└── README.md
```

## Local Preview

Open `index.html` directly in a browser, or run a local server:

```bash
# Python 3
python3 -m http.server 8080

# Node.js (npx)
npx serve .
```

Then visit `http://localhost:8080`

## Deployment

This is a static site. Deploy to any static host:

- **GitHub Pages** — push to a repo and enable Pages
- **Netlify / Vercel** — drag the folder or connect the repo
- **Cloudflare Pages** — connect repo or upload files
